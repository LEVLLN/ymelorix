# Получение токена

← [README](../README.md)

Токен выдаётся по OAuth-флоу, назначенному **официальному мобильному клиенту Яндекс Музыки**.
Откройте в браузере, будучи залогиненным в нужном аккаунте:

```
https://oauth.yandex.ru/authorize?response_type=token&client_id=23cabbbdc6cd418abb4b39c32c41195d
```

Подтвердите доступ на экране согласия. После редиректа токен окажется в адресной строке,
во фрагменте после `#`:

```
https://music.yandex.ru/#access_token=y0_AgAAAA...&token_type=bearer&expires_in=...
                          ^^^^^^^^^^^^^^^^^^^^^^^
```

Скопируйте значение `access_token` в `YANDEX_TOKEN`.

## Что это за client_id

`23cabbbdc6cd418abb4b39c32c41195d` — идентификатор приложения «Яндекс Музыка» для Android.
В OAuth `client_id` обозначает не пользователя, а **приложение**, которое просит доступ:
в выданном токене зашито, кому он выдан, для какого аккаунта и с какими правами. Значение
публично по устройству протокола (секретом является `client_secret`) — мобильное приложение
носит его в своей сборке и предъявляет при авторизации, поэтому оно давно известно и
используется всеми сторонними клиентами Музыки.

Аккаунт и данные при этом ваши — меняется лишь то, за каким приложением числится токен.

## Почему не подходит собственное OAuth-приложение

`api.music.yandex.net` — внутренний API мобильных клиентов, а не публичный интерфейс.
Он проверяет, какому приложению выдан токен, и список допущенных приложений закрытый.
Токен стороннего приложения проходит гейтвей (значит, не `401`), но отвергается музыкальным
бэкендом:

```json
HTTP 403  {"result":{},"invocationInfo":{"app-name":"music-accounts",...}}
```

Включение любых разрешений Музыки в своём приложении этого не меняет: дело в самом
приложении, а не в скоупах токена. Заголовок `X-Yandex-Music-Client` тоже ни на что не
влияет — это самодекларация версии клиента, приложение определяется исключительно токеном.

Заголовок не настраивается: всегда отправляется крейтовый `YandexMusicAndroid/24023621`.

Способ неофициальный: Яндекс может в любой момент закрыть выдачу токенов по этому `client_id`,
и тогда всё перестанет работать.

## Обращение с токеном

Токен даёт полный доступ к аккаунту — обращайтесь с ним как с паролем. Держите его только в
переменной окружения, не коммитьте и не вставляйте в логи и issue. Отозвать выданный доступ
можно на [id.yandex.ru](https://id.yandex.ru) → Безопасность → Приложения. Что делает с
токеном сам загрузчик — в разделе [«Безопасность»](../README.md#безопасность).

Для запуска по расписанию токен кладётся в отдельный файл, а не в строку crontab —
см. [регулярную выгрузку](cron.md#1-токен--в-отдельный-файл).
